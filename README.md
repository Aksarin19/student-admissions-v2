# ระบบรับสมัครเรียนออนไลน์ครบวงจร (Student Admission System V2)
**สำหรับสถานศึกษา สังกัดสำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.)**  
พัฒนาต่อยอดจากโครงสร้างข้อมูลเดิม (Google Sheets / Web App / AutoCrat) สู่ระบบ Full-stack Web Application สมบูรณ์แบบ

---

## 🌟 ฟังก์ชันการทำงานหลักของระบบ (Features)

### 1. ฟังก์ชันสำหรับผู้สมัครเรียน (Front-end)
* **ระบบกรอกใบสมัครและการตรวจสอบความถูกต้อง (Data Validation):**
  * ตรวจสอบ **เลขประจำตัวประชาชน 13 หลัก** ด้วยสูตรคำนวณ Check Digit ตามมาตรฐานกรมการปกครอง (MOD 11) แบบเรียลไทม์
  * ตรวจสอบ **เบอร์โทรศัพท์ 10 หลัก** (ขึ้นต้นด้วย 0 พร้อมจัดรูปแบบขีดอัตโนมัติ)
  * ตัวเลือกแบบ **Dynamic Dropdown** สำหรับระดับชั้น (ปวช./ปวส.) และสาขาวิชา โดยปรับเปลี่ยนสาขาตามระดับชั้นที่เลือกอัตโนมัติ
  * จัดการข้อมูลครบถ้วน: ประวัติส่วนตัว, ข้อมูลผู้ปกครอง, สถานศึกษาเดิม, GPAX และช่องทางที่ทราบข่าว
* **ระบบอัปโหลดเอกสารหลักฐาน (Document Upload):**
  * รองรับการแนบ: รูปถ่ายหน้าตรง, สำเนาบัตรประชาชน, สำเนาทะเบียนบ้าน และใบแสดงผลการเรียน (รบ./ปพ.1)
  * จำกัดประเภทไฟล์เฉพาะ `.JPG`, `.PNG`, `.PDF` และจำกัดขนาดไม่เกิน **5 MB**
  * รองรับระบบ **Drag & Drop** และแสดงสถานะไฟล์พร้อมขนาดไฟล์ทันที
* **ระบบตรวจสอบสถานะการสมัคร (Status Tracking):**
  * ค้นหาด้วยเลขประจำตัวประชาชน 13 หลัก
  * แสดงแผนผังขั้นตอน (Status Timeline): ยื่นใบสมัคร → ตรวจเอกสาร → ผ่านการคัดเลือก → มอบตัวเสร็จสิ้น
  * หากสถานะเป็น **"เอกสารไม่ครบ"** ระบบจะแสดงข้อความจากเจ้าหน้าที่ พร้อมฟอร์มให้ **อัปโหลดเอกสารแก้ไขส่งใหม่ได้ทันที**
* **ระบบสร้างและพิมพ์เอกสารอัตโนมัติ (Automated PDF Forms):**
  * พิมพ์/บันทึก **ใบสมัครเข้าศึกษาต่อ (A4)** พร้อมข้อมูลผู้สมัคร, รายการเอกสารที่แนบ, และช่องลงลายมือชื่อ
  * พิมพ์/บันทึก **หนังสือมอบตัวและสัญญาค้ำประกัน (A4)** พร้อมระบุรหัสนักศึกษาอย่างเป็นทางการ (ทดแทน AutoCrat ด้วยความเร็วแบบ Real-time)

### 2. ฟังก์ชันสำหรับเจ้าหน้าที่และผู้ดูแลระบบ (Back-end & Admin)
* **ระบบจัดการและตรวจสอบข้อมูลผู้สมัคร (Applicant Management):**
  * ตารางรวมรายชื่อผู้สมัครที่สามารถค้นหาและกรองได้ตาม: ปีการศึกษา, ระดับชั้น (ปวช./ปวส.), สาขาวิชา และสถานะการสมัคร
  * หน้าต่างดูข้อมูลและไฟล์แนบ (Document Preview Modal) สามารถเปิดดูรูปถ่ายและเอกสาร PDF ได้โดยตรง
  * ระบบปรับเปลี่ยนสถานะการสมัคร (รอตรวจสอบ, เอกสารไม่ครบ, ผ่านการคัดเลือก, มอบตัวแล้ว, สละสิทธิ์) พร้อมส่งข้อความหมายเหตุถึงผู้สมัคร
* **ระบบออกรหัสประจำตัวและจัดการการมอบตัว (Enrollment & Student ID Generator):**
  * บันทึกข้อมูลการมอบตัว: วันที่มอบตัว, พยาน/ผู้รับมอบตัว, ข้อมูลผู้ปกครอง
  * **ออกรหัสนักศึกษาอัตโนมัติ (Auto Student ID)** ตามมาตรฐาน สอศ. เช่น `69209010001` (ปี 2 หลัก + รหัสสาขา 5 หลัก + ลำดับ 4 หลัก) หรือระบุรหัสด้วยตนเอง
* **แดชบอร์ดสรุปสถิติแบบเรียลไทม์ (Dashboard & Analytics):**
  * กราฟแท่งแสดงยอดผู้สมัครแยกตามสาขาวิชา
  * โดนัทชาร์ตแสดงสัดส่วนระดับชั้น ปวช. vs ปวส.
  * กราฟอันดับสถานศึกษาเดิม (Top Feeder Schools)
  * กราฟวงกลมแสดงสัดส่วนผู้สมัครแยกตามจังหวัด
  * กราฟวิเคราะห์ช่องทางการประชาสัมพันธ์และผู้แนะนำแนะแนว
* **ระบบส่งออกข้อมูลตามมาตรฐาน ศธ.02 (Export Data):**
  * ส่งออกเป็นไฟล์ **Excel (.xlsx)** จัดรูปแบบคอลัมน์มาตรฐานของงานทะเบียนอาชีวศึกษา (ศธ.02)
  * ส่งออกเป็นไฟล์ **CSV (UTF-8 with BOM)** รองรับภาษาไทยสมบูรณ์แบบ ไม่เป็นภาษาต่างดาวใน Microsoft Excel
* **ระบบแจ้งเตือนอัตโนมัติ (Notification System):**
  * รองรับการเชื่อมต่อ LINE Notify / LINE Messaging API Webhook
  * แจ้งเตือนเมื่อมีผู้สมัครรายใหม่ และเมื่อเจ้าหน้าที่ตรวจเอกสารเสร็จสิ้น
  * มีระบบทดสอบการแจ้งเตือนและกล่องบันทึกประวัติการแจ้งเตือน (Notification Log)

## 🚀 วิธีการติดตั้งและรันระบบ (Quick Start)

### 1. เปิด Terminal ในโฟลเดอร์นี้
```bash
npm start
```
หรือ
```bash
node server.js
```

### 2. เข้าใช้งานผ่านเว็บเบราว์เซอร์
* **หน้าเว็บสำหรับผู้สมัครเรียน:** [http://localhost:3000/index.html](http://localhost:3000/index.html)
* **หน้าเว็บสำหรับเจ้าหน้าที่ (Admin):** [http://localhost:3000/admin.html](http://localhost:3000/admin.html)
* **แดชบอร์ดสรุปสถิติ (Analytics):** [http://localhost:3000/dashboard.html](http://localhost:3000/dashboard.html)
